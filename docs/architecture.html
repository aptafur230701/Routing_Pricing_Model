Routing & Pricing Model — arquitectura de agente

AM · PPO — Attention Model entrenado con Proximal Policy Optimization

Un encoder Transformer construye embeddings del grafo de nodos; un vector de contexto ht alimenta dos cabezas — un pointer decoder (actor) y un MLP de valor (critic) — que se entrenan conjuntamente con PPO-Clip sobre rollouts de ruteo.

03

ContextNetwork — vector ht

attention_encoder.py · ContextNetwork

Concatena el embedding global, el embedding del nodo actual, las features temporales y de mercado, y las proyecta a un único vector de contexto compartido por ambas cabezas.

MLP de contexto

[graph_emb ⊕ current_node_emb ⊕ temporal(3) ⊕ market(1)] → Linear(259→128) → ReLU → Linear(128→128) → LayerNorm

h_t : (1, 128)

Loop de entrenamiento PPO

am_training.py · run_am_training()

Ciclo iterativo: recolecta rollouts con la política actual, calcula ventajas con GAE, y actualiza actor y critic con la pérdida PPO-Clip antes de volver a recolectar.

Rollout

act_with_value() × 700 episodios/update

→

GAE

A_t, R_t por episodio

→

PPO-Clip loss

min(surr1, surr2) − H·coef + MSE(V,R)

→

AdamW × 2

actor + critic, 4 épocas, batch 256

γ = 0.99 λ (GAE) = 0.95 clip ε = 0.15 entropy_coef = 0.08 → 0.02 (decay lineal) grad_clip = 0.5 lr actor = 3e-5 (AdamW, wd 1e-4) lr critic ≈ 10× lr actor
